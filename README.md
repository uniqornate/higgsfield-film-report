# Higgsfield Film Report

Interactive English report of a reviewed set of 4,572 Higgsfield film records. This is not a complete inventory of the platform.

The report contains public project credits spent, model usage weighted by generation count, project sizes and original Higgsfield source links. Missing data is explicitly labeled.

GitHub Pages publishing source: main branch, repository root. The entry point is index.html; the adjacent snapshot JSON must be published with it. No server or build step is required.

## Data scope

Public project values were collected on October 13, 2026. Distinct project IDs are counted once in aggregate totals. Model weights cover records with available model data and generation counts. Project GB is rounded source metadata, not final video size or unique storage. Public aggregate vote counts were not found in the inspected project payloads.

CSV exports and the full Markdown report are included. This deployment is a static snapshot; publishing updates does not itself recollect source metadata.
